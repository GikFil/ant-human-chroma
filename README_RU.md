# ant!human SCALE

**ant!human SCALE** — экспериментальный VST3-эффект для спектральной перестройки гармоник под выбранную тональность. Он вдохновлён общей идеей spectral pitch quantization, но имеет собственную реализацию DSP и интерфейс; это не копия кода или интерфейса Xynth Audio Chroma.

## Возможности первой версии

- Спектральное перемещение частотных составляющих к ближайшим нотам выбранной гаммы.
- 12 тоник: C–B.
- 7 ладов/гамм: Major, Natural Minor, Major Pentatonic, Minor Pentatonic, Harmonic Minor, Dorian, Chromatic.
- `AMOUNT` — сила квантования.
- `DRY / WET` — баланс необработанного и обработанного сигнала.
- `COLOUR` — умеренное подчёркивание частот, близких к нотам выбранной гаммы.
- `MORPH` — подмешивание исходных спектральных амплитуд к обработанным.
- `GATE` — подавление слабых спектральных составляющих.
- `PITCH` — предварительная транспозиция перед квантованием.
- `MIDI ROOT` — включение смены тоники по входящим MIDI Note On. В MIDI-режиме класс высоты последней принятой ноты становится тоникой.
- Встроенный спектральный индикатор.

## Технические ограничения этой версии

Это первая экспериментальная реализация, а не полная функциональная копия Chroma. Используется FFT 2048 с перекрытием 75%, поэтому постоянная задержка составляет **2048 сэмплов** (около 46 мс при 44,1 кГц). Перемещение отдельных спектральных бинов может давать характерные фазовые/металлические артефакты на сложных материалах, особенно на транзиентах и низких частотах. Для начала попробуй `AMOUNT` 20–60%, `MIX` 30–70% и `GATE` на минимуме.

В этой версии нет выбора размера FFT, отдельного MIDI-режима для каждой ноты аккорда, multi-rate DSP или продвинутого фазового трекинга пиков. Эти функции можно добавлять после проверки базовой сборки и звучания.

## Сборка без Visual Studio на твоём ПК

Проект настроен на облачную сборку через GitHub Actions:

1. Создай новый репозиторий GitHub, например `antihuman-scale`.
2. Загрузи **содержимое** этой папки в корень репозитория. Не убирай папку `.github/workflows`.
3. Открой вкладку **Actions**. Workflow `Build Windows VST3` запускается автоматически после push; также его можно запустить вручную через **Run workflow**.
4. После успешной сборки открой завершённый запуск и скачай Artifact `antihuman-SCALE-Windows-x64-VST3`.
5. Распакуй архив. Скопируй папку `ant!human SCALE.vst3` целиком в:

   `C:\Program Files\Common Files\VST3`

6. В FL Studio открой **Options → Manage plugins → Find installed plugins**.

## Локальная сборка

Требуются CMake 3.22+, C++17 и поддерживаемый JUCE 9.0.5 toolchain. Конфигурация:

```bash
cmake -S . -B build -A x64
cmake --build build --config Release
```
